## 独立部署与定时任务

局域网地址由部署命令输出；公开演示见 [明前奶绿 Demo](https://your-live-eye-demo.pages.dev/)。服务根目录是独立私有状态下的不可变静态版本，通过原子指针切换。没有依赖 Hinome 目录、数据库、模型文件、服务器、域名、素材或正在运行的全量分类队列。

状态和独立运行环境保存在操作系统的用户应用数据目录，服务与定时任务按 UID 隔离；真实路径和操作日志不进入仓库。

每日北京时间 04:00 为成功更新界线；15 分钟唤醒，成功后当天不重复调用，失败和休眠后补齐已结束场次。已安装 macOS launchd，并实际运行当天检查返回 `up_to_date`；失败不推进检查点和跨时区日期已有自动测试。尚未到第二天实际触发时间，不能把安装和手动触发验证写成“已连续运行多天”。Linux/Windows 安装器已提供，未声称本次已在这两平台安装真实定时任务。

## 失败与修复记录

1. macOS launchd 从外置盘启动失败：改为内部 Application Support 的独立运行环境，源码可移动。
2. 默认端口被其他页面占用：改用可用端口，保留其他服务。
3. 外置盘 AppleDouble 元数据进入初始打包：使用无元数据的临时源码副本构建，排除 `._*`；安装包内核对不包含私有状态。
4. 首版强度遗漏：保留旧版，补跑评分，随后统一新数据的分类/强度输出；保留各次原始回执。
5. 更名重启时停止服务的 TIME_WAIT 连接被探测误当占用：探测与 HTTPServer 使用相同的地址复用策略，只在真实端口可绑定后启动，不关闭无关进程。
6. Chrome/应用内浏览器自动控制出现超时及旧画面，Safari 尝试也未取得稳定视觉结果。新建 Mac Chrome 窗口最终显示正确品牌和评分，已保存截图；下钻自动化仍受阻，没有假报 Mac 全部交互通过。Windows 完整交互验收通过。
