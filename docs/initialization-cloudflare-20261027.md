## 实际实现

1. `run` 与来源选择默认 `all`；`--demo` 明确切到最近场次，`--date` 支持指定日期。`--configure-only` 只解析身份并保存配置，不调用模型。
2. 正式全历史日更检查全目录，包含迟到的更早档案和此前未结束的场次。未变化来源复用；最近三天/数量变化来源复查。单来源失败继续导入其他场次，成功分类保留，失败未清除前不发布新页面或推进成功检查点。
3. 时间/时区支持 `--update-at` / `--timezone`，默认 04:00 Asia/Shanghai。本机 15 分钟检查；每个周期最多一次自动尝试，失败保留检查点、下一周期补跑，每个已耗尽批次只增加一次工程重试；手动可立即恢复。锁占用不消耗日更机会。
4. Cloudflare Action 提供手动 publish/update 和 UTC 20:00 每日触发。使用自托管持久 runner、当前配置与模型；仅导出静态页面给 Wrangler，不将原始数据或库放进公开缓存/artifact。变量、Secrets、runner 标签和操作步骤已列在部署文档。
5. `.agents/skills/your-live-eye-setup/SKILL.md` 随源码分发、根 AGENTS.md 路由；复用用户已确认选择，不重复问。需给预计总时间范围、首次页面可见时间、实测依据；没有同配置记录时先小批测量。运行中每 5 分钟修订进度/剩余时间，最后列预计与实际墙钟。
